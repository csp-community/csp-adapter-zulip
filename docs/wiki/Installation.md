## Pre-requisites

You need Python >=3.10 on your machine to install `csp-adapter-zulip`.

## Install with `pip`

```bash
pip install csp-adapter-zulip
```

## Install with `conda`

```bash
conda install csp-adapter-zulip --channel conda-forge
```

## Source installation

For other platforms and for development installations, [build `csp-adapter-zulip` from source](Build-from-Source).
